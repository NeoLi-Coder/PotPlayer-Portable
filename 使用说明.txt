PotPlayer 便携版（madVR）

本包只保留 PotPlayer 播放器，使用 madVR 作为视频渲染器，并保留 LAV、字幕插件、Icaros、皮肤和扩展。MPC-HC、MPC-BE 和完美解码设置中心已移除。
目录仍为 Pure-Codec-Portable-Full。设置使用注册表，这是无需运行安装程序的绿色迁移包。后续维护本目录，可通过管理窗口导出迁移 ZIP。

管理窗口
双击根目录“PotPlayer管理.exe”打开工具，不需要安装 Python 或 Tauri；“启动.cmd”也会转到此窗口。
左侧导航切换四个页面，Ctrl+1 至 Ctrl+4 可快速切换。窗口可缩放；小窗口下内容可滚动。
“常用操作”：启动播放器、madVR 托盘与 Icaros，保存当前配置、初始化、检查文件、注册组件、创建桌面快捷方式和登记视频关联。
“配置与备份”：按名称、日期或组件搜索，按备份类型筛选；下方显示已选数量。选择一项，可双击或按 Enter 查看恢复范围，也可右键打开备份目录或恢复。Ctrl 多选、Shift 连选、Ctrl+A 全选后，可点击“删除所选备份”或按 Delete，确认后移入回收站；“全选”只选择当前筛选结果。当前 Data 配置和正在使用的设置不受影响。代码备份和旧 MPCVR 预设不属于播放器配置，不列入此列表。
“迁移导出”：选择当前已保存的 Data 或历史配置，导出完整便携包或仅配置包，可选 ZIP 或文件夹。
“配置导入”：选择或拖入以前导出的 ZIP、配置目录，也可粘贴路径后按 Enter 检查；检查通过后，点击“导入并覆盖应用”。完整便携 ZIP 也可直接作为配置来源，只读取设置，不执行包内程序。更换来源后需要重新检查。
窗口底部显示操作状态，“显示记录”可展开详细日志，Alt+L 可展开或收起；操作失败时自动展开。操作执行期间不允许启动另一项操作或关闭工具。

保存与恢复
调整播放器或 madVR 后，关闭 PotPlayer、按键工具、madVR 托盘和 Icaros 配置，再点击“保存当前配置”。
保存会捕获当前注册表设置，生成 Data/Snapshot-*，同步 Data 和 madVR/settings.bin。导出默认使用最后保存的 Data，不自动重新应用固定画质预设。
恢复或导入会覆盖所含组件的设置，并重置该组件中源配置没有保存的额外选项；备份不含的组件保持现状。认证信息保留目标电脑原有状态。
操作前自动备份当前注册表、Data 和 madVR/settings.bin；失败时尝试恢复操作前状态，并在操作记录中给出结果和备份位置。
Icaros 设置只有勾选时才恢复或导入，需要管理员权限；不覆盖 Icaros 内部的系统登记备份。播放列表只在勾选恢复且备份包含时还原。
恢复文件关联登记会恢复当时的打开命令与图标路径，不修改 Windows UserChoice；若旧目录已失效，可重新点击“注册视频关联”。

迁移导出与导入
完整便携包：内含 PotPlayer、组件、皮肤、长按按键工具、管理窗口和所选配置，顶层目录为 PotPlayer-Portable。排除旧备份、配置快照、播放列表、观看记录、临时文件及初始化位置标记。
仅配置包：用于让另一台电脑现有的同版本便携包采用所选设置；包含组件配置、来源目录和完整性清单，不含播放器程序。
默认导出文件使用日期命名；文件夹导出遇到同名目录时使用带日期的新名称，不覆盖已有目录。ZIP 保存对话框在覆盖已有 ZIP 前会询问。
在另一电脑解压完整便携包后，打开管理工具，先初始化本目录，再注册 madVR 和字幕组件；按需要创建桌面快捷方式和登记视频关联。
导入配置会将原组件路径改为当前目录，并同步 Data 和 madVR/settings.bin。原认证信息、Windows 默认应用保持现状；显示器或音频设备不同，需要检查对应设备设置。
首次使用、换电脑、换用户或移动目录后，点击“初始化本目录”。系统组件注册需要管理员权限，窗口会按需请求系统提权；其他操作使用当前用户。
同一用户下，各份 PotPlayer 会共享注册表设置，请使用当前准备维护的便携目录。
应用自己保存的最佳配置时，不需要点击“应用固定画质预设”；该按钮会恢复随包附带的固定 madVR 预设。

右方向键操作
从管理窗口“启动 PotPlayer”、桌面快捷方式或已登记的视频文件关联启动，按键工具会随播放器启动，最后一个本包播放器退出后自动结束，不设置开机自启。
短按右方向键：松开时执行原有快进操作，保留 PotPlayer 当前快进步长。
持续按住约 0.3 秒：进入 3 倍速播放，不连续快进；松开固定恢复 1 倍速。
长按期间切换到其他窗口或按下 Ctrl、Alt、Shift 等修饰键，也会恢复 1 倍速。
仅在本包播放器播放窗口接管单独的右方向键；设置窗口、播放列表、输入框及组合快捷键不接管。当前紫色皮肤保持原样。
直接运行 x64/PotPlayerMini64.exe 不会启动按键工具；请使用根目录 PotPlayerPortable.exe 或上述入口。
倍速使用本包现有的 0.1 倍调节步长，请保持该步长；松开不会恢复到长按之前的其他倍速。
源码保存在 Tools/PotPlayerPortable.cs，编译程序为根目录 PotPlayerPortable.exe；两者与便携包一起保留。

画质优先配置
面向 RX 6700、2560×1440 / 120Hz 显示输出，以及主要观看 1080p / 2K 真人电影和动漫的用途。
图像放大：NGU Standard，高质量。自动选择倍增方式，不额外添加锐化或颗粒。
色度放大：Jinc（3 taps），启用抗振铃。
图像缩小：Lanczos（3 taps），启用抗振铃和线性光处理。
抖动：Error Diffusion 2，保留线性光抖动处理。
去色带：低强度，淡入淡出时中强度；保留自动反交错，不额外启用降噪或锐化。
关闭以硬件色度缩放替代 madVR 色度算法、降低字幕质量、跳过去色带渐变角度分析等对应性能捷径。
保留已有显示设备、HDR、色彩、音频和硬件解码设置，不强制切换系统 HDR 或显示刷新率。
这是一套已通过接口回读的画质配置。长时间播放是否持续掉帧、不同电影和动漫的实际观感，仍需实际片源确认；并非通用“最优值”。
若持续掉帧，可在 madVR 的 scaling algorithms / image upscaling 中将 NGU 质量从 high 改为 medium，确认后点击“保存当前配置”。
“应用固定画质预设”使用 Data/madVR-画质优先.reg；“保存当前配置”同步 Data/madVR.reg，不改变固定预设。
“应用固定画质预设”会恢复整套 madVR 快照，包括当时的显示设备设置；迁移到其他显示器时，需在 madVR 中检查设备属性。

备份、移动与共存
初始化、恢复配置、导入配置和应用固定预设前的备份保存在 Backups，可在“配置与备份”页面恢复。
初始化只处理 PotPlayer 和保留组件的设置，不导入 MPC-HC、MPC-BE、完美解码设置中心或 MPCVR 配置；原来的 MPCVR 文件保留为备用，管理工具不注册或配置它。
Data/ActiveLocation.json 核对当前电脑、用户和目录；变化后须重新初始化才能保存。
本包与安装版会共享该用户的注册表设置。madVR 的系统注册当前指向本目录，安装版若使用 madVR，也会加载这里的组件。
移动后须重新注册 madVR；注册有效期间不要直接删除目录。删除前可用管理员命令行 regsvr32 /u 注销 madVR/madVR64.ax，并在 Icaros 配置中停用已激活的功能。
已有播放列表、历史记录、皮肤和备份保留。外部媒体路径、音频设备偏好和 Windows 默认应用，换电脑后需自行检查。
Backups 中的注册表恢复是合并操作，不自动删除新加入的键值。

卸载安装版后使用
卸载前关闭相关程序，在管理窗口保存当前配置；卸载后初始化本目录，再注册组件并检查文件。
Icaros 缩略图若被停用，在其配置工具中重新激活。视频默认打开方式如失效，点击“注册视频关联”，再在 Windows 默认应用中选择 PotPlayer 便携版。
支持 MP4、MKV、AVI、MOV、WMV、FLV、WEBM、M4V、TS、M2TS、RMVB；只登记当前用户的打开方式，不直接改写 Windows UserChoice。
文件关联和桌面快捷方式使用绝对路径，移动便携包后必须分别更新。

工具文件
PotPlayer管理.exe：原生管理窗口；Tools/PortableManager.cs：窗口源码；Tools/Portable.Core.ps1：配置、恢复和迁移操作。
PotPlayerPortable.exe：播放器启动与长按按键工具；Tools/PotPlayerPortable.cs：按键工具源码。
无需安装 Python、Node 或 Tauri。请将程序、Tools、Data 与组件目录一起保留。
